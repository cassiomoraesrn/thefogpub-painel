Backup e restauração

Enquanto não existe um servidor de verdade por trás do painel, os dados ficam só neste navegador. Baixe um backup de vez em quando — principalmente antes de testar algo novo, ou se estiver com informação importante de um evento real cadastrada aqui.

Restaurar um backup substitui todos os dados atuais pelos do arquivo — vale a pena baixar um backup do estado atual antes, se não tiver certeza.

Hoje este painel atende UM estabelecimento por vez (The Fog Pub). Gerenciar vários clientes/estabelecimentos numa mesma conta (trocar de "workspace") é um passo arquitetural maior, que faz sentido planejar como próxima fase — quando o negócio pedir.
